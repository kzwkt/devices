## Overview
True wireless earbuds with 32 dB ANC, multipoint and a 50 ms low-latency mode.

| Part | Detail |
|---|---|
| Playtime | About 7 h (ANC off, 60% volume), about 5.5 h (ANC on); 120 h total with the case |
| Charging | Buds up to 1 h, case 2.5 h, USB-C fast charging; standby 75 h |
| Bluetooth | 5.4, range 10 m, multipoint, AAC and SBC |

| ANC | 32 dB, plus transparency mode |
| Water resistance | IPX4 |
| Weight | 3.8 g per bud, case 45.6 g |
| Latency | 50 ms low-latency mode |
| App | Ultima Link |
| Operating range | 0 to 45 C, 5 V |

## Controls

| Action | Gesture |
|---|---|
| Play / pause | Tap either bud twice |
| Previous / next | Left bud thrice / right bud thrice |
| Volume up / down | Right bud once / left bud once |
| Answer or end call | Either bud twice |
| Reject call | Hold either bud 2 s |
| Voice assistant | Right bud four times |
| Gaming mode | Left bud four times |
| ANC / normal / transparency | Hold right bud 2 s |
| Balanced / signature EQ | Hold left bud 2 s |
| Reset | Touch one bud 10 times (red LED flashes 5 times), or long-press the case reset button with buds inside |

LED: flashing white on a bud means charging. On the case, flashing white means charging while plugged in, solid white means full.
